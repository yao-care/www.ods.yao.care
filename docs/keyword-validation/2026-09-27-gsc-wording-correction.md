# 2026-09-27：用 GSC 實際查詢字回頭校正標題用字（選字四步的第 4 步）

起因：站台上線滿月後第一次逐頁比對 GSC 的 query × page，發現**排名不差但用字對不上**的一批頁。
近 28 天（08-27～09-24）全站曝光 10,509、點擊 217（前一個 28 天是 24 曝光、0 點擊），
流量集中在 `/templates/`（66 點擊）、`/receipt/`（59）、`/private-documents/`（32）。

## 這一輪刻意不做的：不為每個 .docx 各開一個下載落地頁

`public/downloads/**` 有 62 個 .docx，其中 46 個已經有自己的內容頁（cases 23、citizens 9、private 14），
另外 16 個空白範本掛在 `/templates/` 一頁上。「每個檔各開一頁、鎖定〈文別〉word 下載」這個念頭被下面三件事否掉：

- **公文族群的單一文別沒有量**：`2026-08-27-combo-zero-resolved.md` 量到「公文範本」是實訊 0
  （中文＋中文組合，不是 API 切不出來的那種 0），市場的詞是「公文格式」300；
  「開會通知單」主詞本身只有 21。拆成 5 頁是把 `/templates/` 自己的訊號切碎去搶 21 的字。
  同一份文件對「公文格式 word」的處置已經是「站上 `/templates/` 已經在做這個意圖，**維持現狀即可**」。
- **民間書件那幾個文別有量，但站上已經各有一頁在吃**（委託書 1,865／切結書 958／和解書 829／
  借據範本 858）。再開一個「委託書空白範本」頁是自己跟自己互搶，而 09-26 的反思才剛確認
  全站沒有任何一個查詢對應兩個以上網址。
- 同型判例三次都選不另開頁：出差旅費的相鄰字（`2026-08-26-demand.md`）、問句型
  （`2026-08-27-combo-zero-resolved.md`）、人工智慧基本法（`2026-08-28-demand.md`）。

依據的用字結論（`2026-08-27-combo-zero-resolved.md` 第 4 點）：
**「範本／範例」後綴在民間書件是主要搜法**（借據範本 858 > 借據 435、收據範本 647、
委託書範本 347、離婚協議書範本 374），**在公文則不是**（公文範本 0 而公文格式 300）。
所以這一輪民間書件那批一律改成「範本」，公文那批**沒有動「範例」兩個字**，
只把機關實際在說的詞（內部簽呈、敘獎公文、會勘公文、借用場地公文、會議通知單）補進標題。

沒有新增或刪除任何網址，所以 `seo-ops` 的 `trackUrls` 與 sitemap 筆數不變。
