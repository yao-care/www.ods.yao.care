## 三個結論

### 一、`/templates/` 是本站形狀最對的頁，但它是唯一「Google 未知」的頁之一

「開會通知單範例」「公文格式 word」「公文範本下載」三個字的 SERP 前排**清一色是可下載的
.doc/.docx/.odt**，使用者要的就是一個能填的檔案。`/templates/` 提供的正是照政府文書格式參考規範
ODT 原始檔量出真值產生的 .docx——形狀完全對味，而且比各校 PDF 好用（PDF 不能填）。

這頁 08-19 才上線，目前 `coverageState` 是 `URL is unknown to Google`。

### 二、存證信函那一組是量最大的，但現在的頁面答非所問

搜尋者要的是：**存證費首頁 50 元、續頁 25 元；掛號回執 51 元；4 頁總計約 191 元；要印三份
（寄出／郵局備查／自存），有副本再加一份；單面列印、左側釘書機、右上角蓋寄件人章、每頁騎縫章；
帶信封與三份到郵局、拿掛號回執單貼信封背面、約一週收到回執**。

本站 `/citizens/certified-letter/` 對這些字的覆蓋率實測：

```
費用 0   郵資 0   多少錢 0   一式三份 0   份數 0
掛號 0   回執 0   幾天 0    法律效力 0   時效 0
恐嚇 0   對方不理 0   沒回應 0   起訴 0
郵局 1（只出現在「用紙請至中華郵政官網下載」）
```

本站給的是「一封範例信 → 24 條格式檢核 → Word 下載 → 建立工作區」。
**格式檢核是使用者已經決定要寫、而且已經寫完之後才有價值的東西**；搜「存證信函怎麼寫」的人
還在更前面一階，他連要不要寄、怎麼寄、多少錢都還沒搞清楚。

競爭者不只是內容站：萬建樺律師事務所已有**免費的存證信函產生器**。

### 三、「公文格式檢核」這個字要拿掉

SERP 前排全部在講電子公文系統的操作問題（附件、核章、判行、退回）。在真實承辦的語彙裡，
「退件」指的是流程與核章，不是文字格式。本站 24 條檢核講的是主旨長度、分項句末標點、
國字大寫金額——是另一件事。釘著這個字，等於讓自動化天天對著一個結構上拿不到的意圖優化。

## 內容缺口（要追上面「可追」的字，得補什麼）

1. **存證信函的決策資訊**：費用怎麼算（含實例）、要印幾份、蓋章與騎縫、郵局怎麼寄、
   回執多久收到、寄了有什麼效力、對方不理下一步、不能寫什麼（恐嚇／謾罵）。
   ⚠️ 這些是事實型內容，涉及郵政資費與法律效果，**必須查中華郵政官方資費與法規原文**，不得推估。
2. **公文用語表**：起首語／稱謂語／期望語／准駁語的可查表格（對上級／平行／下級各用什麼），
   而不是只在案例裡零星提到。
3. **`/templates/` 的下載入口要更前面**：使用者要的是檔案，不該先讀一段說明。

## 沒有回答的問題

- 這些字的實際搜尋量沒有數據。SERP 觀察只能判斷「有沒有人在做這個字」與「意圖是什麼」，
  判斷不了量。等自家 GSC 累積到有訊號再校正——**回頭校正日：2026-09-20**。
- 「公文 AI」的競爭者叡揚是系統整合商，走的是機關標案不是自然搜尋；這個字的商業價值可能
  不在 SEO 而在品牌辨識，先留著觀察。

## 這一波最重要的發現

**`/writing/` 原本是錯的。** 它教「主旨、說明、辦法」三段式，但那是「函」的結構；
「簽」是「主旨、說明、<strong>擬辦</strong>」。手冊還明訂「簽之各段應截然劃分，說明段不提擬辦意見，
擬辦段不重複說明」。本站有一則簽的案例卻沒講這件事，等於教錯。已補。

**訴願有三十日，而且要遞給原處分機關。** 訴願法第 14 條的期間自處分達到或公告期滿之
**次日**起算；第 58 條規定訴願書要「經由原行政處分機關」向訴願管轄機關提起——不是直接寄上級。
這兩條是選錯就沒救的東西，比任何範例都前面。教育部的官方問答另外點出：對政府發布的**法規**
有意見只能請願或陳情，不能提訴願。

## 還沒做的

**函 vs 書函的實務差異**（用印：函蓋首長簽字章或職章、書函蓋機關條戳；行文層級：函原則逐級、
書函可直接行文）。手冊「十七」與用印章節都有原文，`/doc-types/` 現在只寫「比函輕」。
判定為可做但優先度低於上面三項。
