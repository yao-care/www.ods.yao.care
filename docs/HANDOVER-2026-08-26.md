## 一、卡在額度：SERP 驗證做不了

```

2. 實搜看 SERP 前排是不是搶得到的   ← ❌ 卡住
3. grep 自家 repo 確認用詞          ← 可以做
```

2026-08-26 這個 session 已用滿 200/200。

腳本在 `/tmp/…/scratchpad/serp.py`，沒有保留到 repo，因為它不work。

**解法**：新 session（額度重置），或請用戶調高 `CLAUDE_CODE_MAX_WEB_SEARCHES_PER_SESSION`。
